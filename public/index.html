Background

I started programming physics and control systems in Garry's Mod, using E2 / Wiremod to build vehicle dynamics, suspension, and telemetry.

That experience led to the same kinds of problems in standalone software: trajectory solvers, vehicle autonomy, and tools for collecting and examining real data.
